# Referencias y créditos

## Créditos del código
- **Notebook 01** adapta y corrige el enfoque de: Paialunga, P. (2021). *Weather forecasting with Machine Learning, using Python*. Towards Data Science. https://towardsdatascience.com/weather-forecasting-with-machine-learning-using-python-55e90c346647/
  Cambios: separación entrenamiento/prueba sin fuga de información, modelos SARIMA estacionales, benchmark ingenuo, métricas fuera de muestra, tendencia de calentamiento y grados-día.
